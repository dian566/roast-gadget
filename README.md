# One-Line Roast: The Gadget You Use Every Day — Union Hours

A one-line roast for the make.fun bounty of the same name. A phone
battery clocks out at 4 PM like it has union quitting time, and then
the very app that drained it asks for a five-star rating.

Running `python3 main.py` glues the two clauses with a spaced em dash
and writes the 125-character roast to `/output/entry.txt`. The file
holds exactly 125 characters (127 bytes), with no trailing newline.
